## Changelog

## 한국어

원본 instant-p2p 모드 **1.5.1**, 가맹점 모드는 **F4.0.2** 기준입니다. 1.3.0에서 빠져 있던 **유저 신고 기능**을 채웠습니다.

### 추가
- **유저 신고 증거 조회 응답(원본 1.5)**: 신고를 시그널링 서버가 검증할 때 방장에게 묻는 채팅·표지판·책에 답합니다(공식·가맹점 공통).
  - 채팅: 신고 시각 앞뒤의 방 안 채팅(최근 150줄). 방이 열려 있는 동안만 **메모리에** 담고 방을 닫으면 지웁니다. 디스크에 쓰지 않습니다.
  - 표지판: 신고에 실린 좌표의 지금 글을 월드에서 읽어 답합니다.
  - 책: 신고에 실린 책의 내용 **해시**만 답합니다(내용은 보내지 않습니다).
  - 분당 6회까지만 답하고 불러오지 않은 청크는 건드리지 않습니다.
  - Paper/Spigot·Fabric은 채팅·표지판·책, Velocity는 월드가 없어 채팅만 답합니다.

### 알아 둘 점
- 월드 이벤트 기록(블록·사망 등)과 클라이언트의 채팅 자동 검사는 서버 통합판에서 하지 않습니다.
- Paper 26.3에서 표지판 글·책 해시를 월드에서 읽는 것까지 확인했습니다. 시그널링 서버가 실제 조회를 보내는 때에는 닿지 못해 서버 쪽 처리까지는 확인하지 못했습니다.

**업데이트:** jar만 바꾸고 재시작하면 됩니다. 설정과 데이터는 그대로 이어집니다.

## English

Targets the original instant-p2p mod **1.5.1** and the franchise mod **F4.0.2**. Fills in the **user-report feature** that was missing in 1.3.0.

### Added
- **Answers to user-report evidence queries (original 1.5)**: when the signaling server verifies a report it asks the host for chat, signs and books; the server edition now answers (official and franchise).
  - Chat: in-room chat around the report time (latest 150 lines), kept **in memory** only while the room is open and cleared when it closes. Nothing is written to disk.
  - Signs: the current text at the coordinates in the report, read from the world.
  - Books: only a **hash** of the books in the report; the content is not sent.
  - At most 6 answers per minute; unloaded chunks are never touched.
  - Paper/Spigot and Fabric answer chat, signs and books; Velocity has no world and answers chat only.

### Notes
- World-event logging (blocks, deaths, …) and the client's automatic chat scanning are not done by the server edition.
- Verified up to reading sign text and book hashes from the world on Paper 26.3. The signaling server never sent a real query during the test, so the server-side handling is unverified.

**Updating:** replace the jar and restart. Settings and data carry over.

## Notes (Modrinth 설명용 — 선택)

- 직접 시험한 서버: Paper 26.3(표지판·책 읽기, 신고 접수). Fabric·Velocity·Spigot의 신고 증거 응답은 빌드와 로드까지만 확인했고 실제 월드 읽기는 직접 시험하지 못했습니다.
