## 한국어

원본 instant-p2p 모드 **1.5.1**, 가맹점 모드는 **F4.0.2** 기준입니다. 1.3.0에서 빠져 있던 **유저 신고 기능**을 채웠습니다.

### 추가
- **유저 신고 증거 조회 응답(원본 1.5)**: 클라이언트에서 접수된 신고를 시그널링 서버가 검증할 때 방장에게 묻는 세 가지에 서버 통합판이 답합니다. (공식·가맹점 공통, 공개 방 로비 연결로 옵니다)
  - **채팅**: 신고 시각 앞뒤 구간의 방 안 채팅(최근 150줄). 방이 열려 있는 동안 방 안 채팅만 **메모리에** 최근 600줄·3일치까지 담고, 방을 닫으면 지웁니다. 디스크에 쓰지 않으며 시그널링 서버가 물을 때만 나갑니다.
  - **표지판**: 신고에 실린 좌표의 지금 표지판 글(앞면+뒷면)을 월드에서 읽어 답합니다.
  - **책**: 신고에 실린 책(독서대·액자·떨어진 아이템·접속자 손/인벤토리)의 내용 **해시**만 월드에서 읽어 답합니다(내용 자체는 보내지 않습니다).
  - 분당 6회까지만 답하고 채팅 구간은 10분 이하만 받습니다(원본과 같음). 아직 불러오지 않은 청크는 건드리지 않습니다.
  - **지원 범위**: Paper/Spigot·Fabric은 채팅·표지판·책 모두, Velocity는 월드가 없어 **채팅만** 답합니다.

### 알아 둘 점
- 월드 이벤트 기록(블록 설치/파괴, 사망 등)과 클라이언트의 채팅 자동 검사는 여전히 서버 통합판에서 하지 않습니다. 방 기록에는 입퇴장·명령·서버가 살아 있다는 신호만 보냅니다.
- 신고 증거 응답은 Paper 26.3에서 표지판 글과 책 해시를 월드에서 읽는 것까지 확인했고, 실제 신고 접수까지 시험했습니다. 시그널링 서버가 조회를 보내는 시점(운영자가 신고를 열 때로 추정)에는 닿지 못해 **서버 쪽 처리까지는 확인하지 못했습니다.**
- 채팅은 받는 쪽에 보이는 문장 기준으로 남깁니다(채팅 플러그인이 형식을 바꿔도 보이는 대로). Velocity는 프록시가 본 채팅을 `<이름> 내용`으로 남깁니다.

**업데이트:** jar만 바꾸고 재시작하면 됩니다. 설정과 데이터는 그대로 이어집니다.

## English

Targets the original instant-p2p mod **1.5.1** and the franchise mod **F4.0.2**. Fills in the **user-report feature** that was missing in 1.3.0.

### Added
- **Answers to user-report evidence queries (original 1.5)**: when the signaling server verifies a report filed from a client, it asks the host three things; the server edition now answers them (official and franchise, delivered over the public-room lobby connection).
  - **Chat**: in-room chat around the report time (latest 150 lines). While the room is open only in-room chat is kept **in memory** (up to 600 lines / 3 days) and cleared when the room closes. Nothing is written to disk and it leaves the server only when the signaling server asks.
  - **Signs**: the current text (front + back) of the signs at the coordinates in the report, read from the world.
  - **Books**: only a **hash** of the books named in the report (lectern, item frame, dropped item, a player's hand/inventory) is read from the world and sent; the content itself is not.
  - At most 6 answers per minute, and chat windows over 10 minutes are ignored (same as the original). Chunks that are not loaded are never touched.
  - **Support**: Paper/Spigot and Fabric answer chat, signs and books; Velocity has no world, so it answers **chat only**.

### Notes
- World-event logging (block place/break, deaths, …) and the client's automatic chat scanning are still not done by the server edition. The room log only carries joins/leaves, commands and the "server is alive" signal.
- Evidence answers were verified up to reading sign text and book hashes from the world on Paper 26.3, and a real report was filed. The signaling server never sent a query during the test (probably when an operator opens the report), so the **server-side handling is unverified.**
- Chat is recorded as it appears to recipients (even if a chat plugin changes the format). On Velocity the proxy-seen chat is recorded as `<name> message`.

**Updating:** replace the jar and restart. Settings and data carry over.
